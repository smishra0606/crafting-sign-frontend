## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Make sure you have the following installed:
* [Node.js](https://nodejs.org/) (v14 or higher recommended)
* npm or yarn

### Installation

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/smishra0606/crafting-sign-frontend.git](https://github.com/smishra0606/crafting-sign-frontend.git)
    cd crafting-sign-frontend
    ```

2.  **Install dependencies**
    ```bash
    npm install
    # or
    yarn install
    ```

3.  **Environment Configuration**
    Create a `.env` file in the root directory and add your environment variables:
    ```env
    REACT_APP_API_URL=http://localhost:5000/api
    # Add other keys like Firebase configs or 3rd party API keys here
    ```

4.  **Start the development server**
    ```bash
    npm start
    # or
    npm run dev
    ```

    The app should now be running on `http://localhost:3000`.

## 📜 Scripts

* `npm start` / `npm run dev`: Runs the app in development mode.
* `npm test`: Launches the test runner.
* `npm run build`: Builds the app for production to the `build` folder.
* `npm run lint`: Scans the code for linting errors.
